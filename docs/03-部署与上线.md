# 部署与上线

从零到能在手机上打开，一共 9 步。**第 3、4、5 步是最容易卡住的地方，别跳。**

## 0. 前置

- 微信小程序账号（个人主体即可）：https://mp.weixin.qq.com → 注册 → 拿到 **AppID**
- 微信开发者工具（稳定版即可）：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
- 本项目已通过静态自检：`node scripts/validate.js`

## 1. 导入项目

开发者工具 → 导入项目 → 目录选 `ebike-map` → AppID 填你自己的 → 不使用云服务模板。

导入后把 `project.config.json` 里的 `"appid": "TOURISTAPPID"` 改成你的真实 AppID（工具导入时通常会自动改）。

## 2. 开通云开发

工具顶部「云开发」按钮 → 开通 → 选**基础版 1**（有免费额度，个人项目够用）。

开通后记下**环境 ID**，形如 `ebike-map-3g9k2x`。

打开 `miniprogram/utils/config.js`：

```js
cloudEnv: 'YOUR_CLOUD_ENV_ID',   // ← 换成你的环境 ID
```

> 不改这里，所有云函数调用都会失败，页面会一直转圈。

## 3. 建集合与索引（必做）

云开发控制台 → 数据库：

**① 建集合** `spots`
（或先跳过，等下用 `spotInit` 自动建）

**② 集合权限** 改成「**所有用户不可读写**」
前端不直接读库，全部走云函数，云函数不受这条限制。这样攻击面最小。

**③ 加索引** —— 控制台 → 数据库 → `spots` → 索引管理 → 添加索引：

| 字段 | 类型 | 作用 |
| --- | --- | --- |
| `location` | **地理位置** | 不加这个，「附近」用 geoNear 会直接报错 |
| `status` | 升序 | 列表过滤 |
| `province` | 升序 | 按省筛选 |
| `brand` | 升序 | 按品牌筛选 |
| `_openid` | 升序 | 我的上传 |
| `createdAt` | 降序 | 排序 |

`location` 那条最关键，类型一定选「地理位置」，不是「升序」。

## 4. 上传云函数

工具左侧资源管理器 → `cloudfunctions` 目录，对**每个**子目录右键：

```
右键 spotList   → 上传并部署：云端安装依赖
右键 spotSubmit → 上传并部署：云端安装依赖
右键 spotReport → ...
右键 spotMine   → ...
右键 spotInit   → ...
右键 geoReverse → ...
```

6 个都要传，一个都不能漏（漏了那个功能点就会报 `cloud function not found`）。

**`spotSubmit` 额外两件事**：

1. 它带 `config.json` 声明了 `security.msgSecCheck` 权限，上传时工具会提示，确认即可
2. 控制台 → 云函数 → spotSubmit → 配置 → **超时时间改 10 秒**（默认 3 秒，冷启动+内容安全接口可能超时）

## 5. 灌示例数据 / 建集合

云开发控制台 → 云函数 → `spotInit` → 云端测试，依次传：

```json
{ "action": "init" }
```
```json
{ "action": "seed" }
```

`seed` 会写入 8 条示例数据（深圳/北京/杭州/成都等），这样一打开就能看到效果。

**正式运营前一定要清掉**：

```json
{ "action": "clearSeed" }
```

查看当前数据量：`{ "action": "stats" }`

## 6. 申请位置接口权限（否则手机上定位会直接失败）

小程序后台 https://mp.weixin.qq.com → **开发 → 开发管理 → 接口设置**：

| 接口 | 申请理由（可直接抄） |
| --- | --- |
| `wx.getLocation` | 用于获取用户当前位置，展示周边已收录的共享电动车投放点，属于用户主动触发的位置服务 |
| `wx.chooseLocation` | 用于用户上传共享电动车投放点时，在地图上选点确认具体位置 |

个人主体也能申请，通常 1 个工作日内出结果。**没通过之前，模拟器里能定位、真机上会失败。**

## 7. 用户隐私保护指引（不上这个，2023 年 9 月后的基础库直接调不了位置接口）

小程序后台 → **设置 → 服务内容声明 → 用户隐私保护指引**，勾选并填写：

- **位置信息**：用于查找并展示附近共享电动车投放点、上传时确认投放位置
- **相册（选择图片）**：用于上传现场照片（选填功能）
- **摄像头**：用于现场拍照上传（选填功能）

代码侧已经对齐：`app.json` 里有 `"__usePrivacyCheck__": true`，`utils/location.js` 在定位前调用 `wx.requirePrivacyAuthorize`。

## 8. 真机验证清单

工具里点「预览」→ 手机扫码。逐项确认：

- [ ] 首页能加载（说明云环境 ID 填对了、云函数传上去了）
- [ ] 点「定位」→ 出现微信授权弹窗 → 允许 → 列表按距离刷新
- [ ] 切到「地图」→ 能看到绿色 pin → 点 pin 弹出底部卡片
- [ ] 选省份 → 列表只剩该省数据
- [ ] 上传一条：选品牌 → 定位 → 选省市区 → 提交 → 回首页能看到
- [ ] 「我的」能看到刚上传的那条，删除生效
- [ ] 详情页点主按钮 → 有 AppID 时能跳转，没有时弹出「复制名称」提示

哪一步失败，先看工具「调试器 → Console」和云开发控制台的云函数日志。

## 9. 提审发布

工具 → 上传 → 填版本号 → 小程序后台「版本管理」→ 提交审核。

提审时在「功能页面」和「补充说明」里写清楚：

- 这是**工具类导航**，不提供租车/支付服务，实际用车在品牌自己的小程序内完成
- 内容由用户上传，已有内容安全检测（`msgSecCheck`）+ 举报入口（3 次自动下架）+ 处理流程
- 位置权限仅用于展示附近投放点

类目建议先选「工具」大类下贴近的二级类目；因为含 UGC，微信可能会要求补充说明或调整类目，按审核反馈改即可 —— 这部分最省事的做法是**先把内容做干净再提**，别带着测试数据去审。

## 常见报错对照

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `cloud function not found` | 云函数没传或名字拼错 | 第 4 步重传 |
| `invalid env` / 一直 loading | `config.js` 里还是 `YOUR_CLOUD_ENV_ID` | 第 2 步 |
| `database collection not exists` | 没建集合 | 跑 `spotInit` 的 `init` |
| `errCode: -502005 database collection not exists` | 同上 | 同上 |
| 附近列表空但种子数据在 | `location` 没有地理索引 | 第 3 步加索引 |
| 定位失败、errMsg 含 `auth deny` | 权限被拒 | 首页「重新定位」→ 去设置里开 |
| 定位失败、`getLocation:fail api scope is not declared` | 后台接口权限没过 | 第 6 步 |
| 定位失败、`privacy permission is not authorized` | 隐私指引没配 | 第 7 步 |
| 上传报「内容包含不适宜信息」 | `msgSecCheck` 命中 | 改文案；确认云函数有 `security.msgSecCheck` 权限 |
| 上传报「接口调用失败 / -604101` | 云函数没有 openapi 权限 | 检查 `cloudfunctions/spotSubmit/config.json` |
