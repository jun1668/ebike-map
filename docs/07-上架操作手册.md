# 上架操作手册

从「代码在电脑上」到「微信里能搜到」，一步一步来。全程不需要写代码，只是点网页、填表、等审核。

> 为什么要这么排：**ICP 备案最慢（1~20 个工作日）且卡住上线**，所以先启动它；备案排队的时候正好去配云开发环境。

---

## 总览：三条线并行

| 线 | 做什么 | 耗时 | 能不能并行 |
| --- | --- | --- | --- |
| A | ICP 备案 | 1~20 个工作日 | ✅ 提交完就等着 |
| B | 云开发环境 + 代码配置 | 约 1 小时 | ✅ 等备案时做 |
| C | 后台配置（类目/隐私/接口） | 约 30 分钟 | ✅ 和 B 同时 |

三条都完成才能提审。提审后 1~7 天出结果。

---

## 第 0 步：确认你有账号和 AppID

打开 https://mp.weixin.qq.com ，用微信扫码登录。

- 如果还没有小程序账号：首页点「立即注册」→ 选「小程序」→ 用一个**没注册过公众号的邮箱**
- 主体类型选什么：
  - **个人**：免费，能发布，能做 UGC，但不能用微信支付、不能选需要资质的类目
  - **个体工商户 / 企业**：要营业执照，认证费 300 元/年，类目和名称都宽松

登录后，在「**开发** → **开发管理** → **开发设置**」里找到 **AppID(小程序ID)**，是一串 `wx` 开头的 18 位字符。记下来。

---

## 第 1 步：填 AppID（1 分钟）

打开 `project.config.json`，第 6 行：

```json
"appid": "TOURISTAPPID",
```

改成你的 AppID：

```json
"appid": "wx1234567890abcdef",
```

改完保存。**这一步不做，微信开发者工具连不上你账号，什么都传不了。**

---

## 第 2 步：启动 ICP 备案（立刻做，然后就不用管了）

小程序后台 → 左侧「**设置**」→「**基本设置**」→ 页面底部「**小程序备案**」→ 点「去备案」。

按提示填：

| 要填的 | 怎么填 |
| --- | --- |
| 主体信息 | 和你注册时选的个人/企业一致 |
| 负责人信息 | 身份证、手机号、人脸核验（手机上扫脸） |
| 小程序信息 | 服务内容选「**工具类**」，备注写「共享电单车投放点信息查询」 |
| 前置审批 | 全部选「无」 |

提交后状态会显示「审核中」。**1~20 个工作日**，微信会发通知。

> 备案没下来之前不能提交审核，但**不耽误你开发和调试**，可以先做后面所有步骤。

---

## 第 3 步：开通云开发（10 分钟）

打开微信开发者工具 → 导入 `ebike-map` 目录（选 `project.config.json` 所在的那层）。

顶部工具栏点「**云开发**」按钮 → 开通：

- 环境名称：随便，比如 `prod`
- 计费方式：选**基础套餐**（约 39.9 元/月，新用户 1 个月免费）
- 确认开通

开通后控制台顶部会显示**环境 ID**，形如 `prod-8gxxxxxx`。复制它。

## 第 4 步：填环境 ID（1 分钟）

打开 `miniprogram/utils/config.js`，第 7 行：

```js
cloudEnv: 'YOUR_CLOUD_ENV_ID',
```

改成：

```js
cloudEnv: 'prod-8gxxxxxx',
```

---

## 第 5 步：建集合、传云函数、灌数据（20 分钟）

### 5.1 建两个集合

云开发控制台 → 数据库 → 新建集合：

| 集合名 | 权限 |
| --- | --- |
| `spots` | 所有用户不可读写 |
| `favorites` | 所有用户不可读写 |

权限选「所有用户不可读写」很重要：前端不直接读库，全部走云函数，云函数不受这条限制。这样别人扒不走数据。

### 5.2 建地理索引（不加的话「附近」直接报错）

数据库 → `spots` → 索引管理 → 添加索引：

| 字段 | 类型 |
| --- | --- |
| `location` | **地理位置** |

### 5.3 上传 6 个云函数

在开发者工具左侧资源管理器，右键 `cloudfunctions` 下每个文件夹 → 「**上传并部署：云端安装依赖**」，一个一个传：

```
spotList  spotSubmit  spotReport  spotMine  spotFav  spotInit
```

（`geoReverse` 是可选的，要用腾讯地图逆地址解析才传。）

### 5.4 灌示例数据（可选，但建议）

云开发控制台 → 云函数 → `spotInit` → 测试 → 传参：

```json
{ "action": "seed" }
```

会写入 8 条示例点位（深圳、北京、杭州、成都、南京、青岛、武汉）。**上线前一定要清掉**，见第 8 步。

---

## 第 6 步：后台配置（30 分钟，最容易漏）

### 6.1 服务类目（不填提审直接被拒）

后台 →「设置」→「基本设置」→「服务类目」→ 添加：

| 选这个 | 为什么 |
| --- | --- |
| **工具 → 信息查询** | ✅ 首选，本产品本质是查信息，不提供租车 |
| 工具 → 效率 | ✅ 备选 |

**不要选**「生活服务 → 出行与交通」「交通服务 → 共享单车」，那些要运营资质。

### 6.2 用户隐私保护指引（不配这个，手机上定位直接失败）

后台 →「设置」→「服务内容声明」→「**用户隐私保护指引**」→ 填写。

要勾选并说明的接口：

| 接口 | 用途说明（直接抄） |
| --- | --- |
| `wx.getLocation` | 用于获取你的大致位置，展示附近已收录的共享电单车投放点 |
| `wx.chooseLocation` | 用于在上传时选择车辆所在的具体位置 |

还要在「收集的信息」里勾：**位置信息**。说明写「仅用于展示附近点位和标记上传位置，不用于其他用途，不共享给第三方」。

### 6.3 接口权限申请（不申请 `getLocation` 会报 `api scope is not declared`）

后台 →「开发」→「开发管理」→「接口设置」→ 找到「地理位置」→ 申请：

- `wx.getLocation`：场景选「交通工具/出行」，说明写「展示用户附近的共享电单车投放点」
- `wx.chooseLocation`：同上

一般几分钟到一天通过。

---

## 第 7 步：真机验证（30 分钟，必做）

开发者工具点「**预览**」→ 手机扫码打开。逐项过：

- [ ] 首页能定位到自己所在城市
- [ ] 列表能看到示例点位，点进去详情正常
- [ ] 上传一条：选品牌 → 选位置 → 选省市区 → 提交成功
- [ ] 「我的」能看到刚上传的，能删除
- [ ] 「⋯」收藏一条，切到「我收藏的」能看到
- [ ] 有人贴了 AppID 的点位，点「打开小程序」能跳过去
- [ ] 分享给朋友，卡片能正常显示

哪一步失败，先在开发者工具「调试器 → Console」看报错，再对照 `docs/03-部署与上线.md` 的「常见报错对照」表。

---

## 第 8 步：清数据 + 上传代码（10 分钟）

### 8.1 清掉示例数据

云开发控制台 → 云函数 → `spotInit` → 测试 → 传参：

```json
{ "action": "clearSeed" }
```

或者直接去数据库把 `spots` 里的记录全删掉。

**带着测试数据提审，审核员看到一堆假点位会直接判「内容无意义」。**

### 8.2 上传代码

开发者工具右上角「**上传**」→ 版本号填 `1.0.0` → 备注写「首个版本」→ 确定。

---

## 第 9 步：设为体验版 → 提审（10 分钟）

后台 →「管理」→「**版本管理**」：

1. 找到刚上传的版本，点「**选为体验版**」→ 生成体验二维码，自己再扫一遍确认
2. 点「**提交审核**」

提审要填的：

| 项 | 填什么 |
| --- | --- |
| 功能页面 | 选首页、上传页、我的页三个 |
| 补充说明 | 「本小程序是工具类信息查询，展示用户提交的共享电单车投放点。不提供车辆租赁、不涉及支付。内容有 msgSecCheck 机器审核 + 用户举报，举报 3 次自动下架。」 |
| 测试账号 | 不需要（无登录） |

---

## 第 10 步：审核通过 → 发布

后台 →「版本管理」→ 点「**发布**」→ 全量发布。

发布后 1~10 分钟，微信里搜「附近电驴」就能找到。

---

## 常见驳回理由对照

| 驳回说 | 真实原因 | 怎么改 |
| --- | --- | --- |
| 服务类目与实际功能不符 | 选了出行/租赁类 | 改成「工具 → 信息查询」 |
| 小程序内容不完整 / 无意义 | 带着示例数据提审 | 清空数据库再提 |
| 涉及用户生成内容，需补充资质 | UGC 类审核更严 | 在补充说明里写清审核机制，附用户协议截图 |
| 未配置隐私保护指引 | 第 6.2 步漏了 | 补配置后重新提审 |
| 名称涉及地域/行业词 | 名称问题 | 见 `docs/05-上架清单.md` 第一节 |
| 缺少 ICP 备案 | 第 2 步没做或没过 | 等备案通过再提 |

---

## 最容易踩的三个坑

1. **`YOUR_CLOUD_ENV_ID` 忘了改** —— 小程序打开一片空白，列表永远是空的
2. **隐私保护指引没配** —— 手机上一点定位就失败，但开发者工具里是好的（工具默认放行）
3. **带着示例数据提审** —— 驳回理由写「内容无意义」，你会一头雾水

---

## 时间预估

| 阶段 | 时长 | 备注 |
| --- | --- | --- |
| 第 0~1 步 | 5 分钟 | 有账号的话 |
| 第 2 步备案提交 | 20 分钟 | 提交后就是等 |
| 第 3~6 步 | 1 小时 | 一次做完 |
| 第 7 步真机验证 | 30 分钟 | 建议每改一次都过一遍 |
| 备案审核 | **1~20 工作日** | 唯一的硬等待 |
| 提审 | 1~7 天 | 常见 1~2 天 |

**最快路径：今天提交备案 + 今天做完 3~6 步，等备案下来当天提审。**
