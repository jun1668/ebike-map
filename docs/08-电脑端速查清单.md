# 电脑端速查清单（一小时走完）

> 打勾用。每一步做完就能进入下一步，中途不用回来问。
> 详细说明看 [上架操作手册](07-上架操作手册.md)，这里只留动作。
> 准备：一台 Windows 或 Mac、能扫码的手机微信、`wxce45dccc1bdca479`（AppID，已写进项目）。

---

## A. 装工具（10 分钟）

- [ ] 下载微信开发者工具
      https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
      选「稳定版 Stable Build」，Windows 选 64 位、Mac 看芯片选 x64 或 ARM64
- [ ] 安装完打开，用手机微信扫码登录（要登录成小程序管理员本人）
- [ ] 点「导入项目」→ 选 `ebike-map` 文件夹（里面要有 `project.config.json`）
- [ ] AppID 那一栏会自动读到 `wxce45dccc1bdca479`，直接点「确定」
- [ ] 导入后先别编译，先做 B 段的后台配置

---

## B. 后台配置（20 分钟，浏览器开 mp.weixin.qq.com）

- [ ] **头像**：设置 → 基本设置 → 头像「修改」→ 选 `ebike-logo.png`
      （文件在项目的 `miniprogram/images/logo.png`，或手机的 `Download/DSH-Go/`）
- [ ] **名称**：同一页填 `附近电驴`，提交后进入审核（1~7 天，不挡后面的步骤）
- [ ] **简称**：`附近电驴`
- [ ] **介绍**：`看看附近哪儿有共享电单车。每个点位都是别人上传的，点一下就能打开对应品牌的小程序，直接扫码骑走。`
- [ ] **服务类目**：设置 → 基本设置 → 服务类目 → 选 `工具` → `信息查询`
      ⚠️ 不要选「出行与交通」或「租赁」，那两个要运营资质
- [ ] **用户隐私保护指引**：设置 → 服务内容声明 → 用户隐私保护指引 → 更新
      勾选这三项并写用途：
      - `wx.getLocation` — 用于显示你附近的共享电单车点位
      - `wx.chooseLocation` — 用于上传时标记车辆所在位置
      - `wx.chooseMedia` — 用于上传现场照片
- [ ] **接口权限**：开发管理 → 接口设置 → 地理位置 → 申请 `wx.getLocation`、`wx.chooseLocation`
- [ ] **ICP 备案**：设置 → 基本设置 → 小程序备案 → 去备案
      填主体信息 + 上传证件 + 人脸核验，提交后等 1~20 个工作日

---

## C. 云开发（20 分钟）

- [ ] 开发者工具点顶部「云开发」→「开通」
- [ ] 环境名称填 `prod`，计费方式选「基础套餐」（首月免费，之后约 39.9 元/月）
- [ ] 开通后控制台顶部复制**环境 ID**，形如 `prod-8g7xxxxxx`
- [ ] 打开 `miniprogram/utils/config.js`，把第 7 行的
      `cloudEnv: 'YOUR_CLOUD_ENV_ID'` 改成 `cloudEnv: 'prod-8g7xxxxxx'`
- [ ] 云开发控制台 → 数据库 → 新建集合 `spots`
- [ ] 同上，新建集合 `favorites`
- [ ] 两个集合的权限都选「**所有用户不可读写**」（安全规则走云函数，别给前端直连）
- [ ] `spots` 集合 → 索引管理 → 新建索引：字段 `location`、类型「地理位置」、名称 `location_geo`
      ⚠️ 不加这个，「附近」查询会直接报错
- [ ] 开发者工具左侧 `cloudfunctions/` 下 6 个文件夹逐个右键 →「上传并部署：云端安装依赖」
      `spotList`、`spotSubmit`、`spotReport`、`spotMine`、`spotInit`、`spotFav`
- [ ] 云开发控制台 → 云函数 → `spotInit` → 测试，参数填 `{"action":"seed"}`
      返回 `ok: true` 就说明 8 条示例数据进去了

---

## D. 真机验证（10 分钟）

- [ ] 开发者工具点「预览」，手机微信扫生成的二维码
- [ ] 逐项走一遍：
      - [ ] 首页弹出定位授权，允许后有「附近」列表
      - [ ] 切换「按省份」筛选，列表跟着变
      - [ ] 切到「地图」，能看到标记点
      - [ ] 点进详情，品牌、地址、时间都对
      - [ ] 「上传」页选品牌、选位置、填备注，提交成功
      - [ ] 「我的」页能看到刚上传的那条
      - [ ] 列表点「⋯」→ 收藏 → 「我的」→ 我收藏的，能看到

---

## E. 上线（10 分钟）

- [ ] 清示例数据：云函数 `spotInit` 测试，参数 `{"action":"clearSeed"}`
- [ ] 开发者工具点「上传」，版本号填 `1.0.0`，备注 `首个版本`
- [ ] 后台 → 版本管理 → 开发版本 → 「选为体验版」
- [ ] 自己扫码再走一遍体验版（这一步别省，审核看的和你测的是同一个包）
- [ ] 版本管理 → 提交审核
      审核说明里写：`工具类小程序，用户自行上传共享电单车投放点信息，含内容审核与举报机制，不提供车辆租赁服务。`
- [ ] 审核通过后点「发布」

---

## 之后换代

不用再装工具。改完代码提交，然后：

```bash
git tag v1.0.1 && git push origin v1.0.1
```

GitHub Actions 会自动上传，后台设体验版 + 提审就行。
需要先确认仓库 Secrets 里 `WX_APPID` 和 `WX_PRIVATE_KEY` 都有（已配好）。

## 出错了看这里

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| 首页一直转圈、列表空 | `config.js` 里还是 `YOUR_CLOUD_ENV_ID` | 填真实环境 ID |
| 点定位没反应 / 报 `api scope is not declared` | 隐私指引或接口权限没配 | 回到 B 段补 |
| 「附近」查询报错 | 没建地理索引 | 回到 C 段建 `location_geo` |
| 云函数调用失败 `-501000` | 云函数没上传 | 6 个逐个右键上传 |
| 提审被拒「类目不符」 | 类目选错 | 改回「工具 → 信息查询」 |
| 提审被拒「缺少备案」 | ICP 备案没完成 | 等备案，无法加速 |
