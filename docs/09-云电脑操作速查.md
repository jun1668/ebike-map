# 云电脑操作速查（青椒云 → 小程序上架）

> 一台手机开青椒云，另一台手机扫二维码。
> 全程大约 30 分钟。做完只用把**一个字符串**（环境 ID）发给我。

---

## 事前准备

| 东西 | 在哪 |
| --- | --- |
| 青椒云 App | 这台手机 |
| 微信（已登录你的号） | **另一台**手机，用来扫码 |
| 头像图片 | 云电脑里用浏览器下载，地址见第 3 步 |

---

## 第 1 步 · 开机连上（3 分钟）

1. 打开青椒云 App
2. 主界面找到你的机器，点「开机」
3. 等 1~2 分钟，看到 Windows 桌面（底部有一条任务栏）就算连上了
4. 如果一直转圈「正在尝试重新连接」：**先关掉手机上的 VPN**，再重试

> 连不上别硬等，关掉 App 重开一次。

---

## 第 2 步 · 登录微信后台（5 分钟）

1. 在 Windows 桌面上打开 **Edge 浏览器**（任务栏蓝色波浪图标）
2. 地址栏输入：`mp.weixin.qq.com` 回车
3. 页面出现**二维码**
4. 拿起**另一台手机**，微信扫一扫，手机上点「确认登录」
5. 云电脑上的网页自动跳进后台首页

> 二维码大约 5 分钟失效。看到就马上扫，别放着。

---

## 第 3 步 · 填小程序信息 + 传头像（8 分钟）

进后台后，首页会有一张引导卡片写着「小程序信息 未填写」，点右边的**「填写」**。

如果找不到，直接在地址栏输入：`mp.weixin.qq.com/wxopen/initprofile?action=index`

### 先下载头像

1. 点浏览器**新建标签页**（Ctrl+T）
2. 地址栏粘贴：

```
https://raw.githubusercontent.com/jun1668/ebike-map/main/miniprogram/images/logo.png
```

3. 图片显示出来后，右键 → **图片另存为** → 保存到**桌面**，文件名就用 `logo.png`

### 然后回来填表

| 填写项 | 填什么 |
| --- | --- |
| 小程序名称 | `附近电驴` |
| 小程序简称 | `附近电驴` |
| 小程序头像 | 点「选择图片」→ 选桌面上的 `logo.png` |
| 小程序介绍 | `看看附近哪儿有共享电单车。每个点位都是别人上传的，点一下就能打开对应品牌的小程序，直接扫码骑走。` |

填完点绿色**「提交」**按钮。

看到「提交成功」或页面跳转，这步就过了。

> 如果「选择图片」还是弹 Flash 报错，说明还在用手机浏览器——确认你是在**云电脑的 Windows 里**操作，不是在手机浏览器里。

---

## 第 4 步 · 装微信开发者工具（10 分钟）

1. 浏览器新标签页，打开：

```
https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
```

2. 选 **Windows 64** 的「稳定版 Stable Build」，下载
3. 下载完双击安装，一路「下一步」
4. 装好打开，出现二维码
5. **另一台手机**微信扫码 → 手机上点「确认登录」
6. 选择「小程序」→ 如果提示选择项目，先关掉，我们要做的是开通云开发

---

## 第 5 步 · 开通云开发（5 分钟）★ 关键

在开发者工具**顶部工具栏**，找到**「云开发」**按钮，点它。

1. 弹出「开通云开发」窗口
2. 环境名称随便填：`ebike-prod`
3. 套餐选**基础版**（第一个月免费，之后 39.9 元/月）
4. 点「确定」/「开通」
5. 等 1~2 分钟，开通完成后会显示一个**环境 ID**

环境 ID 长这样（一长串英文数字）：

```
ebike-prod-3g1a2b3c4d5e6f
```

**把这个字符串复制下来，发给我。** 这是整件事的钥匙。

> 找不到环境 ID？在云开发控制台左侧点「设置」→「环境设置」，上面写着「环境 ID」。

---

## 第 6 步 · 关机

做完点青椒云 App 里的「关机」或「释放实例」。按小时计费的机器不关会一直扣钱。

---

## 卡住了对照这张表

| 你看到的 | 意思 | 怎么办 |
| --- | --- | --- |
| 一直「正在尝试重新连接」 | 网络不通 | 关掉手机 VPN，重启 App |
| 登录二维码刷不出来 | 网络慢 | 等 10 秒点刷新，或换个浏览器 |
| 「未安装flash插件」 | 你还在手机浏览器里 | 确认是在云电脑 Windows 里操作 |
| 提交按钮是灰的 | 头像没传上 | 检查红字提示，通常是头像缺失 |
| 「云开发」按钮是灰的 | 未登录或未选小程序 | 重新扫码登录开发者工具 |
| 开通时提示要认证 | 个人主体需先完成认证 | 先跳过，把环境 ID 弄到手再说 |

---

**环境 ID**。

拿到它之后，剩下的全交给我：

- 我把它写进代码配置
- 推 GitHub
