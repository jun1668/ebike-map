# 附近电驴 · 产品需求与规则

## 一句话

一张由用户共建的「共享电动车小程序地图」：你在哪个城市发现哪个品牌的共享电动车，就把品牌和位置传上来；别人到陌生城市打开就能看到、一键跳进对应品牌的小程序。

## 要解决的问题

共享电动车（电单车/助力车）几乎都是**分城市、分区县甚至分景区**投放的，而且品牌很分散：美团、哈啰、青桔、小遛、松果、喵走、人民出行…… 用户到了一个陌生城市，只能一个一个搜、一个一个试，还不一定知道哪个牌子在这儿有车。

**所以核心价值不是「租车」，而是「去哪儿扫」这一层导航。**

## 用户与场景

| 角色 | 场景 | 关键动作 |
| --- | --- | --- |
| 找车的人（占绝大多数） | 出差/旅游到陌生城市，出地铁想找车 | 打开就定位 → 看附近有什么品牌 → 点开直达 |
| 找车的人（跨城查询） | 出发前想知道目的地有没有共享电动车 | 选省份 / 城市浏览，或看地图分布 |
| 贡献者（少数但关键） | 刚扫了一辆车，发现没人收录 | 上传品牌 + 位置，1 分钟内完成 |

贡献者的动力来自「刚刚我自己也找不到」的即时情绪，所以上传入口必须极短：**品牌 → 位置 → 提交**，其余全部选填。

## 功能清单（v1.0 已实现）

### 首页 / 附近
- 定位：首次点「定位」才申请权限，不打扰；已授权则启动时静默定位
- 双视图：**列表**（按距离/时间）与 **地图**（marker 点选弹出卡片）
- 筛选：省份 picker、品牌横向 chips、关键词搜索（品牌/城市/地址）
- 空状态：没有收录时直接引导「我来上传一个」，并把当前定位带过去
- 卡片右上角「⋯」：任何人可「确认仍可用」或「已经下架了，删除这条」；长按卡片另可复制品牌名、举报

### 详情
- 品牌、省市区、地址、备注、照片、收录时间
- 小地图预览 → 点击拉起微信原生地图导航
- 主按钮：**打开该品牌小程序**（有 AppID 时）/ **复制名称去搜索**（没有时）
- 举报：信息失效、位置不对、广告或无关内容
- 「这辆车已经下架了？任何人都可以删除它」：任何人都能下架这条记录，删除前必须先确认已下架

## 城市视角

用户真正的问题往往不是「我脚下这辆是什么车」，而是「这个城市有什么车」。

- **按城市找**：首页「列表 / 地图」右侧入口，进入全部已收录城市的索引，按省分组，每城显示「N 个品牌 · N 个区 · N 个点位」，品牌多的城市排在前面
- **城市详情**：绿色统计条（品牌数 / 区县数 / 点位数）+ 按品牌分组；点某个品牌带着筛选条件回首页
- **空城市**：显示「你来当这个城市的第一个」，按钮直达上传并预填城市；下方同时给出三个主流品牌的「微信搜一下」入口，让急着用车的人先去用，不白跑一趟
- **分享带城市**：分享标题形如「深圳市有 5 个共享电单车点位，都是大家传上来的」，落地页直接是这个城市

## 数据新鲜度

共享电动车点位变化很快，一条半年前的数据对新用户是误导。所以：

- 每条记录展示的不是「收录时间」，而是「上次有人确认的时间」
- 列表按「距离 + 新鲜度」综合排序，不再只看距离
- 超过 **30 天**没人确认：卡片变灰、打「可能已失效」标签、底部出现「30 天没人确认了，还开着吗？」和「还在」按钮
- 点「还在」会刷新这条的确认时间（云函数 `mode: 'confirm'`），等于帮后面的人续上时效
- 整个城市都没人确认时，城市页顶部给一条汇总提示

## 上传
- 品牌网格选择（预置 12 个主流品牌 + 其他），选「其他」时填名称
- 位置：用当前位置 或 地图选点（`wx.chooseLocation`）
- 省市区：`picker mode="region"`，微信原生三级联动（省 → 市 → 区），全国 34 省 / 344 市 / 3000+ 区县全量可选
  - 定位或选点后自动带出省市区：地址文字能认出就直填（`utils/province.js` 的 `guessRegion`），只有坐标时调 `geoReverse` 逆地理解析（需配 `TENCENT_MAP_KEY`，没配则静默跳过，由用户手动选）
- 备注（限 120 字）、现场照片（选填 3 张）
- 备注里可以直接粘贴小程序链接，输入时实时识别并提示：
  - `https://wxaurl.cn/xxx`（微信官方短链）→ 列表显示「可一键打开」，点了直接跳
  - `#小程序://品牌/路径`（微信里复制的分享链接）→ 列表显示「有链接」，点了复制到微信粘贴打开
  - `wx` 开头的 18 位 AppID → 等同填了 AppID，直接跳
- 进阶选填：目标品牌小程序 AppID（填了之后所有人可一键直达；备注里贴 AppID 也认）
- 提交前勾选「信息真实并同意公开分享」

### 我的
- 我的上传列表（含待审核/未通过状态）、覆盖城市数、品牌数
- 修改备注 / 重新定位 / 删除
- 意见反馈（微信原生 feedback 按钮）

## 数据规则

1. **一条记录 = 一个品牌在一个位置可用**。同一城市同一品牌只保留一条最新的（30 天内重复提交会被拦截并提示「已有人传过」）。
2. **按距离查** 依赖地理索引，默认半径 30km，可在 `utils/config.js` 调。
3. **举报达 3 次自动下架**（`status = hidden`），进人工复核；同一用户重复举报只算一次。

### 任何人可下架（不是只有上传者）
共享电动车点位失效极快，只有上传者能删的话，整张地图几个月就会腐化。规则：

| 规则 | 说明 |
| --- | --- |
| 谁能删 | 任何登录用户，不限于上传者 |
| 删除前 | 必须二次确认「确认这辆车已经下架了吗」，明确写入删除的是哪一条 |
| 删除方式 | 软删除：`status = removed` + `removedBy` / `removedAt` / `removedByOwner`，记录保留便于申诉和恢复 |
| 立即生效 | 列表与详情接口只认 `status = approved`，删除后立刻不可见 |
| 防滥用 | 非上传者每天最多下架 20 条，超限提示明天再来；已删除的再删返回 `ALREADY_GONE` |
| 下架后可重新上传 | 去重只比对 `status = approved`，城市里没有有效收录时允许重新提交 |

配套的「**还能用，我来确认一下**」是反向信号：任何人对一条记录点确认，就刷新它的 `updatedAt` 并记入 `confirmers`（同一人重复确认不重复刷）。这样列表的「最近更新」才可信，超过 N 天没人确认的条目运营可以批量标「可能已失效」。
4. **限流**：同一用户 10 分钟内最多提交 5 条。
5. **内容安全**：品牌名、备注、地址提交时过微信 `security.msgSecCheck`，命中违规直接拒绝。

## 审核策略（二选一，改一行代码）

`cloudfunctions/spotSubmit/index.js` 顶部：

```js
const NEED_REVIEW = false
```

- `false`（默认）：内容安全通过即上线。冷启动期必须这样，否则没内容。
- `true`：全部进 `pending`，只有上传者自己能看到，需要人工在云开发控制台改 `status` 为 `approved`。内容量上来、或出现过恶意投稿时切过去。

## 明确不做的事（避免范围膨胀）

- 不做租车、支付、实名——扫车一律交给品牌自己的小程序
- 不做实时车辆库存（拿不到数据，也没有必要）
- 不做用户体系/头像昵称，只认 openid；昵称会引入额外的审核与隐私成本
- 不做私信、评论（UGC 审核成本翻倍，收益低）

## 后续可在同一套结构上加

- 「这车还在吗」的按赞/失效投票（数据模型已留 `upCount`）
- 城市聚合页（`/pages/city?province=广东省`），利于搜索收录
- 运营后台小程序（同云环境，管理员 openid 可看全部 + 批量改状态）
